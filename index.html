METHODOLOGY

使用教學與評分方法

所有計算均可在瀏覽器執行，沒有假裝串接交易 API，也沒有隱藏的 AI 服務。

01 · 如何操作網站？

使用上方搜尋框輸入 2330 或 台積電；切換 K 線時間範圍與均線；從智慧選股表中點選標的；使用股票比較與星號收藏。鍵盤按 / 可直接搜尋。

02 · 技術指標

MA5、MA20、MA60 是最近 5、20、60 個交易日的收盤價平均；RSI14 使用 Wilder 平滑方式估算多空動能；20 日動能是 20 個交易日前後的漲跌百分比。

MA(n) = 最近 n 日收盤價總和 ÷ n
動能(20) = (今日收盤 / 20 日前收盤 − 1) × 100%

03 · 四維評分邏輯

技術面根據價格相對均線與均線排列；基本面用人工設定的模擬本益比、殖利率與估值條件；動能根據近 20/60 日報酬與 RSI；風險根據近 20 日的年化波動率與價格回撤。

總分 = 技術×35% + 基本×25% + 動能×25% + 風險×15%
各子分數限定 0–100，總分四捨五入。

04 · 如何理解分數？

80–100：規則符合度較高；70–79：偏強；50–69：中性觀察；0–49：審慎觀察。這是為教學設計的透明指標，不是買賣訊號、投顧建議或預測模型。

風險分數越高代表依本站規則估計波動或回撤較小；與實際投資風險不同。

05 · Vibe Coding 技術規格

採用原生 HTML + CSS + JavaScript，全部放在單一 index.html；使用 Canvas API 繪製 K 線、均線與比較圖，固定種子產生可重現的 260 日 OHLCV 模擬序列，並透過 localStorage 保存自選股。不需要 Node.js、後端、外部套件、資料庫或 API Key，因此可直接使用 GitHub Pages。

  • 資料性質：2026/10/09 為固定模擬最後日期，不是即時報價。
  • 價格與基本面皆為示範值；個股名稱及代碼僅用來練習搜尋與分類。
  • 產生的資料不適合真實投資決策、歷史回測或績效評估。
  • 使用 GitHub Pages 公開發布後，其他人開啟網址即可操作，資料不會送出到伺服器。
